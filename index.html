3. Automated Daily Star & Rank Sync via GitHub Actions

To keep the star counts and ranks continuously updated without manual work, create this GitHub Actions workflow at .github/workflows/update-stars.yml: 

name: Daily Repo Star Sync
on:
  schedule:
    - cron: '0 0 * * *' # Runs midnight UTC
  workflow_dispatch:

jobs:
  update-repos:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Fetch Latest GitHub Stats
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          python3 update_repos.py
      - name: Commit and push changes
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add -A
          git diff --quiet && git diff --staged --quiet || git commit -m "chore: auto-sync repo stats"
          git push
Action successful!
